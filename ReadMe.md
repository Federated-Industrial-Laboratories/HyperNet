# HyperNet

HyperNet is a proposed invite-based federation for pages, private communication,
file exchange and explicitly authorised service connections.

The project is in design. This repository does not yet provide a runnable
network service or a production security guarantee.

HyperNet defines infrastructure and application interfaces. Its independent
terminal and command-line clients belong to
[HyperNetSuite](https://github.com/Federated-Industrial-Laboratories/HyperNetSuite).
Other clients and integrations can use the same interfaces.

See [Requirements](Documentation/Requirements.md) for the intended contracts.
